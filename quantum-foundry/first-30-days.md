# OEQL — First 30 Days
Attribution: 4 GOD & 4 huMan
Dependency-ordered. Everything in Week 1 requires zero capital and zero
external authorization — it's already startable today.

## Week 1 — zero-capital technical evidence
- [ ] Implement stabilizer-formalism surface-code simulator (integrate
      an existing open tool like Stim rather than reimplement — see
      `research/first-breakthrough-target.md`)
- [ ] Integrate MWPM decoder (PyMatching or equivalent)
- [ ] Reproduce one cited surface-code threshold result; log outcome
      (pass or honest failure) in `research/evidence-ledger.md`
- [ ] Publish the MVP repo publicly (it's already built — this is a
      one-step action: push to a public git host, add topics/README
      badges pointing to the test suite output)

## Week 2 — reduce technical uncertainty + reusable infrastructure
- [ ] Extend the decoder benchmark to a small qLDPC code family
- [ ] Write up the surface-code + qLDPC benchmark results as a
      preprint-style writeup (even a repo `RESULTS.md` counts — doesn't
      need arXiv yet, but should be written in that register: methods,
      reproducibility, honest limitations)
- [ ] Identify 5–10 *named* real targets for the outreach system
      (specific labs/maintainers, not categories) — human task, AI can
      help research who's actually working on qLDPC/decoding right now

## Week 3 — funding readiness + first collaborators
- [ ] Human reviews and sends first 3–5 outreach messages (Template A/B
      from `governance/institution-outreach-system.md`), customized per
      target
- [ ] Identify 2–3 specific, currently-open funding calls that fit an
      open-source software project at this stage (not hardware-scale
      calls yet — this project isn't ready for those) — human task with
      AI research assistance; do not submit anything without the human
      authorization gate (`governance/human-authorization-gate.md`)
- [ ] Draft (not submit) one grant proposal narrative using the real,
      verified evidence ledger as the "prior work" section — never the
      wedge-decision doc's Level-0 industry summaries presented as if
      they were Quantum Foundry's own results

## Week 4 — first demonstrator polish + review
- [ ] Public playground + game get real support/contact links (human
      fills these in — see the placeholder notes already in both files)
- [ ] External (even informal) technical review of the surface-code/
      qLDPC benchmark by someone outside the core team — this is the
      cheapest available step toward Level 4 (independent reproduction)
      evidence, and it's currently missing entirely
- [ ] Governance charter first draft circulated for comment (text
      drafting can start now; ratification is a human/social process
      per the master plan, not a Week 4 completion target)

## What does NOT belong in the first 30 days
Anything requiring a lab, a fab, a signed MOU, a funded grant, or a
mainnet transaction with real value. Per the project's own
readiness-tagging discipline, none of those are unlocked by working
faster on the software track — they're unlocked by real external
partners and real capital, which this 30-day plan is explicitly
building the credibility to go get, not pretending to already have.
