What Quantum Foundry actually built

Every claim below is classified by evidence level. Level 1 = computational result, verified against independent ground truth. Level 0 = hypothesis / research proposal. No physical quantum hardware exists yet — honestly stated, not hidden.

Statevector Simulator

Level 1 — Verified

Exact complex-amplitude simulation. Bell, GHZ, QFT outputs match closed-form quantum mechanics to floating-point precision. Unitarity confirmed. 6/6 correctness checks.

QF-IR Compiler Front End

Level 1 — Verified

QASM-lite text format → circuit IR → simulator execution. Round-trip parse and re-emit confirmed correct. Basis for a backend-agnostic compiler (OpenQASM3 next).

Repetition Code QEC

Level 1 — Verified

Monte Carlo simulation of the bit-flip repetition code cross-validated against the closed-form majority-vote formula from Nielsen & Chuang §10.1, within 6σ statistical tolerance, for distances 3, 5, 7.

Surface Code (Toric MWPM)

Level 1 — Verified

Full toric-code MWPM decoder using exact graph matching. Threshold crossing at ~10–12% physical error rate, consistent with the Dennis/Kitaev/Landahl/Preskill 2002 literature ballpark. Bug found, fixed, documented.

qLDPC Codes (Hypergraph Product)

Level 1 — Verified

Tillich-Zémor hypergraph product construction. CSS orthogonality verified across 15 independent trials. Structured (Hamming) seed codes eliminate single-qubit failures (0/58) vs random seeds (18/45). Distance advantage confirmed at n=241.

Belief Propagation Decoder

Level 1 — Verified

Sum-product BP decoder implemented. Correctness invariant confirmed: convergence always means syndrome solved (200 trials). Honest finding: BP underperforms bit-flip on this small code due to short Tanner-graph cycles — documented, not hidden.

Smart Contracts (Foundry/Solidity)

Level 0 — Written, not audited

ArtifactRegistry, ContributorReputation (soulbound), BountyEscrow written with full test suites. Not compiled or audited yet — needs forge build/test on a machine with network access. Bankr dependency removed entirely.

OEQL Architecture Proposal

Level 0 — Speculative

Open-Ended Quantum Liberty: a substrate-adaptive computing architecture proposal. Self-assessed: introduces no new physics, only a proposed compiler/runtime integration layer. TRL 1. Honestly stated in the document itself.

Governance & Outreach

Level 0 — Draft

Founding charter draft, human authorization gate (any-human-sign-here mechanism), institution outreach system with real named targets (PyMatching, Stim, ldpc library, qLDPC package, Error Correction Zoo).

State Match Puzzle Game

Browser-playable quantum circuit puzzle game running on the real JS-ported simulator. Target states computed by the actual Python engine. Shared leaderboard via persistent storage. Real physics, not a theme.
